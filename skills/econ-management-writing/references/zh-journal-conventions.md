# 中文期刊规范（C刊 / CSSCI）

本文件只写中文经管期刊的**语言特有**要求：篇幅口径、结构偏好、检索习惯与行文。综述的组织与论证、标题摘要关键词的写法见 [文献综述的组织与写作](literature-review.md) 与 [标题、摘要与关键词](title-abstract-keywords.md)，两份通用文件同样适用。

以下篇幅数字是通行区间的经验值，不是强制标准。目标期刊明确时应核对该刊最新投稿须知，不以本文件代替官方要求——这与 [学科与章节规范](discipline-and-sections.md) 开篇的立场一致。

## 1. 摘要

- 篇幅按**字**计，通常 250～350 字。部分刊物上限更严，须核对。
- 结构偏好：**标准顺序**（背景 → 问题 → 方法 → 发现 → 贡献）最常见，审稿人可按要素逐项评估。
- 贡献前置结构在研究贡献特别清晰时也可用；发现前置结构仅在核心发现足够突出时使用。
- 中文摘要忌用"本文认为""笔者认为"反复开头，也忌把摘要写成引言摘要——背景一句即可，其余给研究本身的回答。

## 2. 标题

- 现象聚焦型与问题导向型在中文期刊更常见，读者能快速判断研究范围。
- 理论对话型适合理论驱动研究；结论导向型需要发现可命名。
- 主标题与副标题的分工应清楚：主标题承担核心主张或对象，副标题交代情境、方法或数据，避免两者内容重复。
- 避免在主标题中堆叠两个并列概念的组合式表达，除非正文确实讨论了二者关系。

## 3. 关键词

- **议题检索型**优先：中文期刊读者与检索习惯更依赖研究对象、情境与现象词。5～8 个词。
- 理论+方法型用于希望吸引理论或方法论对话的情形，但不要把未在正文讨论范围的理论名称写进关键词。
- 中文关键词之间用分号或按刊物要求的分隔符，不与英文关键词混排。

## 4. 行文

通用中文行文规则见 [局部修改](local-editing.md) 中的「双语表达」一节，此处只补综述与摘要中集中出现的问题。

- **减少无内容的背景套话**："随着……的不断发展""具有重要的理论意义和现实意义"这类句子不承载信息，删掉不损失内容。
- **减少连续"进一步"**：连续出现说明段落只是在同一层上加话，而非推进论证，应合并或重排。
- **避免多层"基于……通过……从而……"**：一句话里叠加多层手段—目的链，读者难以定位真正的因果环节，应拆成有主次的句子。
- **不堆叠抽象名词**：以"……性、……度、……化、……机制"串成长串名词，把动作还原为动词、对象还原为可指认的事物。
- **不把专业内容改成口语**：可读性不等于通俗化，术语保留，但需说明它在本研究中做什么。
- 关键制度、政策名称与本土情境，首次出现时交代清楚，不假定审稿人熟悉。

## 5. 引用与格式

- 引用格式按目标期刊要求，不默认某一套西文体系。
- 中文文献与外文文献的著录方式可能要求不同，按该刊须知处理。
- 引用归属规则与英文稿一致，见 [证据、引用与实质修改](evidence-and-integrity.md) 第 3 节。

## 6. 适配时的优先顺序

期刊要求与本研究约定冲突时：

1. 期刊的强制格式要求（篇幅、著录体例、匿名规则）优先。中文期刊的字数、摘要、关键词与图表惯例多与英文刊不同，该类要求以该刊须知为准，具体记录项见 [期刊政策记录](journal-policy-record.md)。
2. 术语、变量名、样本口径以项目 [写作约定文件](manuscript-conventions.md) 为准，格式要求不改变所指。
3. 两者都未规定时，用本 skill 的默认规范。
