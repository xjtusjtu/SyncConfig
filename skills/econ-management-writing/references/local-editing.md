# 局部修改：润色与扩写

## L1：段落／小节润色

### 确定这一段的工作

先判断它是在定义构念、提出问题、建立理论联系、交代设计、解释结果还是讨论贡献。可读相邻段落来保证衔接，但不据此修改相邻章节。没有相邻段落时，不编造此前已证明的结果或后文安排。

按以下顺序判断：

1. 主语、对象、指代和逻辑关系是否明确。
2. 核心论断与限定条件是否处于正确位置。
3. 支持材料是否足够，是否混淆已有事实与解释。
4. 冗余或空泛表达能否删除而不丢信息。
5. 句法、词语搭配、人称与节奏是否自然。

不强制所有段落都以结论开头。结果段宜尽早给发现；理论推导可能先交代定义和前提；需要比较两种解释的段落应让比较成立后再得出判断。

### 双语表达

中文：让“谁、在何条件下、通过什么过程、与何结果相关”清楚；减少无内容的背景套话、连续“进一步”、多层“基于……通过……从而……”和名词堆叠。不把专业内容改成口语。

英文：使用学科习惯的准确搭配，保留作者已定义的术语；按表达功能选择主动／被动，按时间含义选择时态。不要为避免重复给同一构念换多个近义词，不人为插入不规则句式来“显得像人写的”。

转折词只有在真实对立时使用。因果连接词需要因果推理，不因句子更流畅而添加。因此、“相关”不能润色成“导致”，“可能解释”不能变成“证明机制”。

### 缺陷处理

原文若把不显著结果写成“没有影响”，或把观测性相关写成机制证明，应说明该句存在实质风险。仅要求保留原意润色时，可给问题句之外的改文，再单列经证据校准的候选句；不要假装改词解决了方法缺陷。

## L2：有证据约束的扩写

### 确定缺的是哪类内容

扩写不是把一句话拆成三句、堆背景、补宏大意义。找到缺少的论证环节，再选择可获得材料支持的增量：

| 缺口 | 有效扩展 | 所需依据 |
|---|---|---|
| 构念模糊 | 定义、与相近构念的区别、研究中的测量含义 | 作者定义或核实文献 |
| 理论跳步 | 行动主体、约束／激励、行为或过程、结果联系 | 已有理论前提；新增推理须标为论证 |
| 推论过快 | 反向力量、适用条件、可观察预测 | 原理论或明确提出的待检验解释 |
| 设计不透明 | 估计对象、比较、变异来源、关键假设 | 实际方法与资料 |
| 结果薄弱 | 数值、精度、量纲、适当基准、证据解释 | 对应表格及已知模型与基准 |
| 讨论空泛 | 具体改变哪项认识、相对什么既有论点、对谁意味着什么 | 当前发现与核实的文献比较 |

### 扩写的证据边界

将新增内容分为：

- 已有事实的重述／解释：可以直接使用，但保持其范围。
- 从已给前提展开的理论推理：以“我们认为／这一逻辑意味着”等合适方式表达，不写成实证发现。
- 新的可检验猜想：明确是待检验解释，不冒充原论文已有结论；较大理论改变先说明。
- 需要新材料支持的事实或文献判断：不进入完成态正文；定位缺口，必要时查原始来源。

没有结果表，不补具体系数、显著性、样本量或收益率。没有材料支撑，不添“已有研究普遍认为”“首次证明”“机制已被验证”。文献检索不可用时，保留具体待补提示，不补看似真实的作者年份。

### 长度与交付

用户给出长度时按其要求控制。未给长度时，以填补实际缺口为限，通常先增加一个必要的论证层次；这不是倍数或句数硬限制。

若原材料只能支持短段落，交付可信部分并解释扩至更长版本还缺什么。不为了满足字数重复概念或虚构结果。

完成前逐句标识自己新增了什么信息，检查依据。用于内部审查的来源标签不必留在可直接提交的正文中；未解决的缺口不能通过移除标签伪装为已解决。

## 教学示例

以下均为原创虚构材料，不是任何真实研究或可引用证据。

### 保留原意的结果润色

原材料：表2中 X 的估计系数为 0.06，95% 置信区间为 [-0.02, 0.14]，结果不显著。没有提供因果设计。

可交付：表2中 X 的估计系数为 0.06，95% 置信区间为 [-0.02, 0.14]，统计上不显著。该区间包含零，也包含正值和负值，因此现有估计不足以确定关系的方向。

检查：未宣称“没有效应”，未转换成“提高 6%”，未补造比较均值。

### 理论展开与实证证明分开

已给前提：协调理论强调信息不对称会增加协作难度；本文认为共享进度信息可能帮助团队及时调整任务。

可展开的论证：共享进度信息使团队成员更容易发现任务推进中的偏差。若成员据此调整任务安排，偏差便不必等到最终交付时才被发现。这一逻辑将信息共享与及时协调联系起来，但其是否实际改善协作结果，仍需相应证据。

检查：增加的是前提内的推理；最后一个结论不能被换成“本研究证明共享信息提高绩效”。这不是新增一种已经验证的理论机制。
