# 学科、范式与章节规范

本文件提供编辑判断，不充当期刊投稿须知。字数、模板、匿名、披露与格式等当前要求，应在用户要求期刊适配时查看该刊官方材料，不沿用固定记忆。

## 1. 先按范式判断，再按领域微调

### 应用经济学／识别导向实证

让读者看清问题为何难答、研究利用什么比较与变异、目标估计对象、必要假设、主要结果的经济含义，以及当前设计仍不能排除什么。

不要把“加入固定效应”“使用机器学习”当成完整识别论证。理论可以简洁，也可以是贡献核心；不为模仿管理学给每个回归造一条 H1/H2。

### 管理学中的理论驱动定量研究

明确构念、理论争议、行为或组织过程、边界条件与证据之间的关系。贡献要说清现有解释的哪一部分被延伸、修正或限定，而不是只说有新数据、新国家或新技术。

假设需要前提与推理，调节变量不能只来自事后显著分组。测量指标并不自动等于理论构念；不要通过改名消除测量与理论之间的缺口。

### 管理科学、运筹、设计科学与方法论文

围绕真实决策或研究难题，交代对象、目标、约束、信息、方法为何解决该难题、对照与评价、适用范围和可执行的启示。

方法本身可以是核心贡献，不要求每篇都包装成组织行为机制。离线模型收益、理论界、模拟和真实部署结果必须分开。Management Science 的具体部门与论文类型不能仅凭刊名推断。

### 理论／结构模型

先让读者理解研究环境、主体、时序、信息和关键权衡，再给形式化内容。区分必需假设与简化假设、命题与直觉、模型内推论与经验事实。

结构估计需区分拟合、识别、参数估计、模型验证与反事实；模型内政策变化不自动成为现实世界已经实现的因果结果。

### 描述性、预测、质性与综述

- 描述性／预测：清楚交代测量、样本、任务、评价与可解释边界，不补造因果处理变量。
- 质性：重视案例选择、过程资料、编码／解释链条、反例与理论抽象，不强套回归显著性。
- 综述：组织争议与证据，解释选择与综合范围；只有实际执行了系统流程才能称系统综述。

学科交叉时按稿件实际问题和方法组合这些判断。不要把 AMJ 风格等同于全部管理学，也不要把应用微观规范等同于全部经济学。

## 2. 按章节承担的任务修改

| 章节 | 核心任务 | 常见需要修复的偏差 |
|---|---|---|
| 摘要 | 问题／理论难题、方法或论证、核心回答、价值与必要范围 | 只说开展了什么；夸张；内部过程占篇幅；塞未支持数字 |
| 引言 | 让读者理解问题、已有解释的不足、本文如何推进与主要回答；首段快速引入核心问题，末段明确交代贡献 | 长背景后才给问题；贡献无证据；承诺主体未兑现；未建立proper frame of reference |
| 文献／定位 | 围绕问题与争议比较最相关工作，明确本文相对位置；需demonstrate the gap in knowledge | 作者年份清单；虚构空白；为了新颖而贬低已有研究；未说清本文填补何种gap |
| 理论／假设 | 定义—前提—过程—边界—预测之间的连续推理 | 只罗列理论名；把预期方向写成推导；先看结果后补假设 |
| 数据／方法 | 说明读者判断测量、比较与可信度所需的实际步骤；每个步骤按「为什么做—给什么输入—怎样处理—得到什么输出」展开 | 只报算法名；隐藏样本选择；把诊断写成识别证明 |
| 结果 | 给核心回答和对应证据，解释量纲、精度与意义 | 逐列念表；只看星号；混淆模型、样本和基准 |
| 讨论 | 解释发现怎样改变认识，处理替代解释与边界 | 重复结果；新机制没有支持；泛泛“丰富文献” |
| 结论／启示 | 汇总回答，说明适用对象、条件和可支持的行动含义 | 宏大口号；引入新发现；将样本内结果普遍化 |

章节布局服务论证。文献可集中在引言，也可单列；实证与理论可以交织；假设并非所有类型论文都必需。不能以模板覆盖作者已合理组织的稿件。

章节内描述方法、算法、数据处理或识别策略时，默认读者不具备本研究的技术背景。新术语首次出现先以普通语言说明其对应的动作或对象，再使用术语；专业术语可保留，但要让读者知道它在本研究中具体做了什么。详细规则见 [读者视角表达](reader-facing-expression.md)。

## 3. 贡献与启示的表达

贡献可以从下列问题检验，而非机械凑三条：

- 本文回答了哪一个原先解释不足或证据不确定的问题？（明确研究gap）
- 改变的是概念区分、机制、边界、识别、测量、决策方法，还是经验认识？（贡献类型）
- 对照哪个具体既有论点？支持来自哪一项理论推导或结果？（具体定位）
- 新情境为什么影响问题或解释，而不只是更换地名？（情境贡献的理论意义）
- 贡献陈述是否informative而非仅descriptive？（顶刊标准：说清楚改变了什么认识）

管理启示宜交代“谁，在何条件下，可以依据什么发现调整哪类决策”；政策启示还需考虑实施、成本、福利与外部适用性。没有成本或福利分析时，不声称最优、净收益为正或应全面推广。

## 4. 语言与长度

不把“中文”理解成政策口号，不把“英文”理解成长词和名词化。行文须对学科同行清楚，但关键制度、局部技术和不熟悉构念仍需解释。

正文不堆叠连续抽象名词（“……性、……度、……化、……机制”叠加成长串名词），把动作还原为动词、对象还原为可指认的事物；不以大量括号和防御性限定承载信息。命名与术语以项目 [写作约定文件](manuscript-conventions.md) 为准，不把代码标识搬进正文。

默认跟随作者一致的人称与时态。数值精度由原始结果和表达需要决定，不为了套风格改系数。没有目标限制时，不硬设摘要 150 词、引言三页、每段五句或全文四十页。
