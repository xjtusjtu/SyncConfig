# 反模板化写作：从源头避免"AI 味"

## 0. 定位

模板化文风是**写作习惯问题**，不是检测问题。本文件给出在起草阶段就要遵守的写作选择，使文本具体、克制、有作者声音。

- 目标：每一句都能被核查；每个形容词都能换成可验证的主张；每段都有自己的逻辑角色。
- **不是**目标：压低任何检测工具的分数。检测器只统计文体特征，与学术质量无关；本 skill 不承诺分数，也不接受"先降分再说"的委托。
- 与 SKILL.md 第 3 节一致：去除空泛与模板化表达，**不以规避 AI 检测为优化目标**；保留作者有定义的术语和声音。
- 冲突时以本 skill 其它规范为准：[证据与保护规则](evidence-and-integrity.md)（不得为"具体"而编数字）、[局部修改](local-editing.md)（不循环换词）、[读者视角表达](reader-facing-expression.md)（步骤可读）、[写作约定文件](manuscript-conventions.md)（术语以约定为准）。

## 1. 为什么要放在起草阶段

模板选择会被后段继承：先写"值得注意的是……首先……其次……最后……显著提升了绩效"，后面无论怎么润色，骨架仍是模板。因此流程是：

1. **起草时**就按第 2–5 节的规则写：先定主张，再选句式，最后填连接词；
2. **成稿后**用第 6 节的自检清单和 `scripts/check_ai_tells.py` 扫一遍；
3. 修的时候先改结构与主张，再改句子——**先修骨架，后修皮肤**；不要逐词替换，被改的句子仍别扭时重写它所在的段落；
4. **改完核对**：事实、名称、数字、日期、引文、排序、以及“两件事同时发生”这类主张不得丢改或被加强（见 [证据与保护规则](evidence-and-integrity.md)）。

如果整段命中模式过密（多个类别同时出现 + 段落长度一致 + 句首同构），逐句换词没有意义：把核心主张用一句话写出来，再按论证需要重建段落。

## 2. 十类高风险写法

| # | 模式 | 为什么像模板 | 改法 |
|---|------|------------|------|
| 1 | 空泛形容词代替主张：显著、全面、有效、重要、新颖、鲁棒、深入 | 没有数字也没有条件，读者无法判断真假 | 换成具体主张：比较对象、变化幅度、成立条件 |
| 2 | 无证据的绝对化：显而易见、毫无疑问、必然、充分证明 | 把推断写成事实，且往往没有证据 | 加限定与依据："在本文设定下""据表 3" |
| 3 | 模糊量化：大量研究、大幅提升、绝大多数 | 数量不可核查 | 给数量、引用或区间 |
| 4 | 填充连接词：值得注意的是、综上所述、不难发现、众所周知、首先／其次／最后 | 这些词承担不了论证功能，只是段落黏合剂 | 删除；让逻辑关系显性化（因为、因此、相对照） |
| 5 | 机械三段式与同构句首：本文提出……本文设计……本文实现…… | 三段式与同句首是生成式文本的指纹 | 打散：让每句承担不同动作，用不同主语与句式 |
| 6 | 模板化段落：开头"近年来，随着……快速发展"；结尾"尽管……面临挑战，未来可期" | 可原样套进任何论文 | 直接从问题、数据或机制入手 |
| 7 | 堆叠并列引用：一句内 3 个以上引用且无逐篇说明 | 把文献当装饰 | 分析性引用：谁做了什么、在什么条件下、留下什么局限 |
| 8 | 元话语：本文旨在、进行了深入分析、从表中可以看出、结果表明该方法 | 描述"写作动作"而非研究内容 | 直接写研究内容与结果 |
| 9 | 空洞领域套话：赋能、闭环、抓手、底层逻辑、深度融合、高质量发展 | 与具体研究无关的宏大词 | 换成具体机制或删去 |
| 10 | 格式噪声：破折号连用、粗体成串、段首符号列表、每段等长 | 与内容无关的整齐感 | 按目标期刊常规排版 |

### 2.1 结构性句式模板

上表按"症状"分类；下表按"生成机制"补充一批更难靠自检发现的结构性模板。识别信号给出中英两套表达，改法一律指向"直接陈述"。

| # | 模式 | 识别信号 | 为什么像模板 | 改法 |
|---|------|----------|--------------|------|
| 11 | 否定对比（Not X but Y） | 不是 X，而是 Y／并非 X，而是 Y／这并不意味着 X。这意味着 Y／不仅仅是 X，更是 Y | 否定的一半提出一个无人主张过的对立面，正的一半因此显得更有力，却没多出任何主张 | 直接陈述；只有当否定纠正读者确实持有的误解、或两半都带信息时才保留 |
| 12 | 单独成段的收束句 | 段落只有一句且很短："这才是真正的收获。""这一区分很重要。""真正重要的是…"；每节末尾同一句式 | 要求读者停顿，而不是补充信息 | 删去重复的收束；只在一句带来新事实或新后果时保留 |
| 13 | 格言化表达 | 真正的问题在于…／说到底／归根结底／本质上／核心在于／X 是 Y 的语言 | 把平常的主张包装成隐藏的真理 | 换成具体主张与其成立条件 |
| 14 | 铺垫式开场 | 让我们深入…／先来看…／需要指出的是／说实话／话说回来 | 宣布要点或表演坦率，而不是给要点 | 删掉铺垫，直接给内容 |
| 15 | 反驳无人提出的异议 | 我不是说…／这并不是主要关于…／有人可能会说…但是／不可否认的是 | 回应的是早期草稿里的幽灵读者 | 删去辩解；若确有主张，直接写主张 |
| 16 | 破折号当万能连接符 | 句中「——」代替因果、转折或补充关系 | 回避选择两个分句的关系 | 改成句号、冒号、逗号，或重写该句 |
| 17 | 标题后重复首句 | 标题下的第一段首句复述标题 | 标题已经承担了这句信息 | 删去重复句 |
| 18 | 段落级三连 | 三个平行短句 + 一句总结式感叹 | 段落尺度的三段式指纹 | 合并，或只展开最强的一项 |
| 19 | 对话残留 | 好问题！／希望对你有帮助／需要我继续吗？ | 聊天场景的包装留在了正文里 | 删包装，留内容 |

### 2.2 程度与权威的失真

| # | 模式 | 识别信号 | 为什么像模板 | 改法 |
|---|------|----------|--------------|------|
| 20 | 赋予重大意义 | 标志着…的重要转折／彰显了…／为…奠定了基础／凸显了…的重要性 | 把一件普通事实说成里程碑 | 保留事实，删去意义；结尾停在最后一个具体事实上 |
| 21 | 含糊关联 | 与…密切相关／与…存在关联／在…方面具有重要作用 | 只说两件事有关，不说是什么关系 | 写出关系；关系未知时保留含糊表述并标为待补 |
| 22 | 浅层动名词短语 | 通过…实现了…／体现了…的价值／有助于…／从而使得… | 给简单事实挂一个动作短语，让它显得更深 | 只留事实；短语只有在确有依据时保留 |
| 23 | 过度限定堆叠 | 一句里出现两个以上"可能／或许／在一定程度上／某种程度上" | 反复加限定通常是在修补先前的过度断言 | 只保留有依据的限定；范围声明、法务与安全声明、真实更正除外 |
| 24 | 回避简单动词 | 作为一个…的重要组成部分／充当…的角色／发挥着…的作用 | 用长词组替换 is／are／has | 改回简单动词；主语明确时用主动句 |
| 25 | 无主语句式 | 存在显著的差异／使得…无法…／进行了深入分析 | 读者不知道是谁做的 | 补出主体；方法部分叙述对象明确时可保留被动 |

三个对照例：

| 模式 | 模板写法 | 改写方向 |
|------|----------|----------|
| 否定对比 | 这并不意味着管理者不重视激励。它意味着激励缺乏可检验的证据。 | 管理者重视激励，但现有证据无法检验激励的效果。 |
| 单独成段收束 | 上述结果表明数字化转型对企业绩效存在显著影响。<br><br>这才是真正的关键。 | 上述结果表明数字化转型与企业绩效正相关（见表 3）。 |
| 赋予重大意义 | 本研究的发布标志着绿色供应链研究迈入新阶段。 | 本研究检验了绿色供应链对减排绩效的影响。 |

### 2.3 单条命中不作为证据

模式清单不是"命中即改"的检测器清单。判定规则：

- **强信号**（出现一次即可动手）：模糊归因、绝对化断言、对话残留、知识截止声明、否定对比（11）、单独成段收束（12）、格言化（13）、铺垫式开场（14）、反驳无人异议（15）、赋予重大意义（20）。
- **弱信号**（需同现才动手）：其余各条，包括破折号密度、限定词堆叠、无主语句式、装饰性标题、段落等长、单个高危词、连续同构句首。
- **同现** = 同一段落或同一小节内出现两个及以上弱信号，或弱信号与任一强信号同现。

理由：这些词面模式可被有经验的作者正当使用，且中文经管论文中的部分句式（对照、限定、被动、图表引导）是期刊体裁要求。把它们当成"命中即错"，会把规范的学术写作改坏。

## 3. 中文替换参考

| 模板写法 | 改写方向 |
|----------|----------|
| 值得注意的是…… | 删去，直接陈述要点 |
| 综上所述…… | 删去，或换成具体推理的收口 |
| 众所周知／不难发现 | 引用具体文献，或让读者从数据看出 |
| 本文旨在…… | 本文关注……／本文检验…… |
| 进行了深入分析 | 做了初步探讨／展开了讨论 |
| 取得了显著成效 | 给出指标、幅度与比较对象 |
| 从表中可以看出 | 表 3 报告了…… |
| 具有重要意义 | 说明它改变了哪项认识、对谁有影响 |
| 显著提升 | 提升了 X%（或改为具体机制描述） |
| 被广泛应用于 | 得到较多运用／在多个领域有所应用 |

英文对应关系：`it is important to note that`（删）、`delve into`（改为 examine / look at）、`testament to`（改为 shows）、`robust`（改为具体的稳定性条件）、`comprehensive`（改为覆盖范围）、`game-changing`（说明具体变了什么）、`utilize`（改 use）、`leverage`（改 use）。

**不动的词**：确有技术含义的术语（robust 在统计语境、framework 在方法论语境）由作者定义和语境决定；不得为了"像人写的"而替换约定术语、破坏术语一致性。

## 4. 英文特有的两点

- **否定排比**："This is not just X, it's Y"／"这不仅仅是 X，更是 Y"：全文最多一处，且必须承担论证作用；多数情况改成直接陈述。
- **成簇才算信号**：单个 `crucial`／`robust` 可能正常；同一段出现两个以上才需要检查。**Tier 1 词表**（delve、tapestry、realm、beacon、testament to、game-changer、utilize、pivotal、meticulous、seamless、holistic、actionable、impactful、unpack、ever-evolving、at its core、deep dive）无论是否成簇都应复核。

作者声音在英文经管论文里是允许的：`we`、明确的判断、作者声音与语气一致即可；不为"显得自然"插入与内容无关的俏皮话或第一人称。

## 5. 分章节应用

| 章节 | 最常见的模板问题 | 改法 |
|------|----------------|------|
| 摘要 | "本文提出了一种新颖方法""具有重要意义" | 写清楚研究问题、识别策略、关键结果（带数字）与边界 |
| 引言 | "随着……快速发展"；贡献写成三条口号 | 从具体问题切入；贡献写成可核查的动作与结果 |
| 文献综述 | 逐篇罗列；堆叠引用；只说"取得了丰硕成果" | 按主题/范式分组，比较分歧与证据，给出定位 |
| 理论 | 概念堆叠；"基于……从而……从而……" | 说清主体、机制、边界条件与可观察预测 |
| 方法 | "我们采用了一个先进模型" | 写清为什么做、给什么输入、怎样处理、得到什么输出 |
| 结果 | "效果非常好""充分证明" | 只报事实与数值，解释留给讨论 |
| 讨论 | "具有重要的理论与实践意义" | 说清改变了哪项认识、相对哪个既有论点、对谁有含义 |
| 结论 | "未来将继续改进" | 回答研究问题，不引入新结果，给具体的后续方向 |

## 6. 交付前自检清单

**高优先级（必须处理）**

- [ ] 无来源的模糊归因（"专家认为""大量研究表明"）——换成具体文献或删除；
- [ ] 无证据的绝对化断言（"显而易见""必然""充分证明"）；
- [ ] 关键主张里的形容词能否换成数字、比较对象或条件；
- [ ] 模糊量化（"大量""大幅""绝大多数"）是否有数量或引用；
- [ ] 一句内 3 个以上引用且无逐篇分析；
- [ ] 对话残留与知识截止声明（若来自与作者的对话稿）。

**中优先级（应当处理）**

- [ ] 填充连接词成串；
- [ ] 机械三段式、连续同构句首；
- [ ] 元话语（"本文旨在""进行了深入分析""从表中可以看出"）；
- [ ] 空洞领域套话；
- [ ] 模板化段落开头与"未来可期"式收尾。

**低优先级（时间允许再改）**

- [ ] 段落长度是否过于一致；
- [ ] 破折号、粗体、段首符号列表的密度；
- [ ] 同构句式与过渡词密度。

词面辅助：

```bash
python scripts/check_ai_tells.py manuscript.md
```

输出 JSON，列出命中位置、类别与优先级（P0 可信度风险／P1 明显模板信号／P2 风格打磨）。它只报信号：同一句话在作者笔下可能完全正当，逐条判断，不追求清零；跳过代码块、公式、引用命令与参考文献表。

### 6.1 何时不要动

- **引文、书名、术语、专名、代码**中出现被监控的词不动；讨论这些词本身的段落也不动；
- **2022-11-30 之前的文本**不按 AI 痕迹处理——本节只约束本次起草与本次改写；
- **承载作者声音的细节要保留**：具体但不寻常的事实、混合态度与未解决的张力、有年代感的引用、作者能解释的第一人称选择、真正的旁白与自我更正；
- **体裁的合法例外**：摘要与引言的有限复述、方法部分的被动陈述、讨论部分的保守限定、与既有文献对话时对他人观点的复述——这些不是模板痕迹；
- **作者的写作样本与目标期刊的既有风格优先于本文件**：若样本大量使用破折号，就按样本的密度保留；
- 与 [证据与保护规则](evidence-and-integrity.md) 冲突时以那份为准：具体只能来自已有材料。

## 7. 不要做的事

- 不要为躲检测随机替换同义词（与 [局部修改](local-editing.md) 的"不循环换词"同向），也不要给同一构念换多个近义词；
- 不要把学术语言改成口语，也不要插入无关的第一人称与感叹；
- 不要为了"具体"补造数字、引用或结果——具体只能来自已有材料，缺口应标为待补；
- 不要在正文里反复插入防御性限定来制造"谨慎"观感（与 SKILL.md 第 3 节冲突，以那条为准）；
- 不要承诺任何检测分数的变化。

## 8. 与外部 humanizer 规则集的边界

本节的模式清单参考了 MIT 许可的公开 skill `blader/humanizer`（v4.0.0）；来源、采用与不采用项见 [来源与取舍](sources-and-decisions.md) §9。以下做法**明确不采用**：

- 不采用"注入人味／注入灵魂"（情绪、幽默、第一人称抒情）：经管论文按目标期刊惯例写作；
- 不采用口语化改写，也不采用面向检测器的 best-of-N 降分流程；
- 不采用词表硬配额（句长上限、每段句数、禁用词频率阈值）：与本 skill"不新增固定句长或机械配额"的立场冲突；
- 不采用英文排版专属规则（直引号／弯引号），也不采用"最终稿不得出现破折号"的绝对禁令：中文期刊的排版惯例不同，破折号密度按目标期刊与作者样本判断；
- 不把"多处命中"当作分数、结论或作者身份判断：命中只是逐条判断的起点。
