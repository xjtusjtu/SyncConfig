# 文献综述的组织与写作

本文件只管**如何组织与表达综述**，不管如何检索文献。文献检索、文献真实性核查不在本 skill 范围；引用必须由作者核实，引用归属规则见 [证据、引用与实质修改](evidence-and-integrity.md) 第 3 节。

综述的功能不是展示读过多少文献，而是把已有研究组织成一条通向本文问题的论证线。判断一篇综述是否合格，看它是否让读者理解：这个领域在争什么、争到哪一步、为什么还差一块、本文补的是哪一块。

## 1. 顶刊综述与博士论文综述不是同一种文体

| 维度 | 顶刊综述 | 博士论文综述 |
|---|---|---|
| 长度 | 2～5 页 | 30～80 页 |
| 目的 | 论证研究空白，支撑研究设计 | 展示全面的文献掌握 |
| 组织 | 主题式、论证式 | 可时间式或逐篇式 |
| 覆盖 | 战略性选取，服务论证 | 力求全面、穷尽 |
| 语气 | 简洁、目的明确 | 可较为描述性 |
| 批判 | 精准指出与本文相关的局限 | 全面评价各研究优缺点 |
| 结构 | 漏斗型，指向研究空白 | 可百科式 |
| 文献关系 | 强调脉络、演进、交汇 | 可独立讨论各研究 |

把博士论文综述的覆盖标准套到期刊稿件上，会得到一份谁都不得罪、也没有论证的清单；反过来把期刊综述的选文策略套到学位论文上，会被质疑文献掌握不足。先确认写的是哪一种。

## 2. 三种结构模式

### 漏斗型（默认）

多数经管实证与理论文章适用。从宏观到微观逐步聚焦：

1. **宏观领域定位（1 段）**：确立研究所在领域，点明其重要性，引用奠基性文献与近期综述。
2. **核心构念的文献脉络（2～4 段）**：按主题组织，不按时间。每段呈现共识 → 分歧 → 未解决问题，构念之间用逻辑衔接句串联。
3. **变量间关系的研究现状（1～3 段）**：聚焦到本文核心关系，呈现已有实证发现的一致性与矛盾性，指出理论解释的不充分之处。
4. **研究空白与本文定位（1 段）**：明确 gap，说明本文如何填补，自然过渡到假设或理论模型。

### 理论驱动型

适用于理论贡献导向的研究，理论本身是叙事骨架：

1. **核心理论的介绍与发展脉络（1～2 段）**：起源、核心主张、关键假设、在本领域的应用历史。
2. **理论的拓展与批评（1～2 段）**：已有延伸、局限或边界条件。
3. **理论与本文变量的结合（2～3 段）**：用该理论视角重新审视核心变量，说明它如何预测变量关系。
4. **理论空白与本文贡献定位（1 段）**：未探索区域与本文的拓展方向。

### 争论型

适用于存在明显理论分歧的领域：

1. **现象或问题的重要性（1 段）**。
2. **观点 A 及支持文献（1～2 段）**：理论逻辑加实证支持。
3. **观点 B 及支持文献（1～2 段）**：对立逻辑加实证支持。
4. **整合与超越（1～2 段）**：说明两种观点各自为何不完整，给出本文的整合视角。

结构模式服务论证，不是模板。选题同时具备理论分歧与新情境时，可以组合使用，但组合要让读者看出主线，而非把三套结构拼成三层标题。

## 3. 段落层面：综合式与串珠式

### 综合式（应采用的写法）

每段围绕一个论点，把多项研究作为支持该论点的证据同时出现，而不是让每项研究各自占一个位置：

1. **主题句**：概括该段要立的主张。
2. **多源综合支撑**：直接并列多项研究，而不是逐个叙述。
3. **差异或条件**：指出这些研究之间细微差别，或结论成立的条件。
4. **批判性评价**：方法、样本或理论层面的局限。
5. **过渡句**：引出下一段要处理的问题。

### 串珠式（应避免的写法）

逐篇叙述各研究了什么，文献之间只有罗列关系：

> Smith（2020）发现 X 影响 Y。Jones（2021）考察了 X 与 Z 的关系。Lee（2022）研究了 X 对 W 的作用。

这类段落读起来像文献清单，读者无法得知作者对这批研究的判断。改写方向不是换词，而是找出这些研究共同回答或共同回避的问题，把主张提到段首，把研究降为证据。

## 4. 段落之间的衔接

衔接句承担论证功能，不是装饰。按需要推进的关系选择：

- **逻辑递进**：建立在已有发现之上继续推进，或从直接效应转向机制、条件、边界。
- **转折对比**：指出解读上的分歧，或指出某类结果被另一条研究脉络挑战。
- **聚焦深入**：把范围收窄到本文关心的特定情境或变量。

三类衔接的共同要求是：删掉衔接句后，如果段落关系仍然清楚，这句衔接就是多余的；如果删掉后读者会误解两段的关系，说明这段衔接承担实际工作。

## 5. 四种综合技术

| 技术 | 用于 | 组织方式 |
|---|---|---|
| 共识综合 | 多项研究结论一致 | 把相似结论合并为一个论点，多源并列引用支撑 |
| 分歧综合 | 结论矛盾 | 并列对立观点，然后解释矛盾可能来自情境、测量或设计差异 |
| 演进综合 | 主题在时间上发生转向 | 早期关注什么 → 注意力如何转移 → 近期前沿 → 仍未解决什么 |
| 条件综合 | 存在调节或边界效应 | 指出关系依赖于什么条件，在何种条件下更强、何时消失 |

分歧综合最容易写坏：把矛盾并列之后不追问来源，读者只得到"学界有争议"的印象。矛盾通常来自样本、情境、测量或识别策略的差异，指出哪一类差异导致分歧，这一节才算完成论证。

## 6. 批判性评价的三个层面

综述中的批判要精准到与本文相关的局限，而不是逐篇打分。

- **方法层面**：设计能否支持该研究想要的推论，样本或情境是否限制外推，测量是否与构念对应。
- **理论层面**：该解释未处理哪个方面，机制是否交代清楚，不同理论是否给出竞争性预测。
- **实证覆盖层面**：哪类情境、哪类对象、哪个变量长期缺席，既有研究是否过度集中在单一场景。

批评已有研究时的常见失误是把对方立场简化后再批评。批评对象应是原文实际主张，而不是一个更容易反驳的版本。

## 7. 引出研究空白

空白必须由前文的论证自然导出，不能靠一句"尚缺乏研究"宣告。

三种导入方式：

- **直接声明**：明确指出此前没有研究处理过该问题。适用于确实无人做过的情形，措辞保守（"据现有检索"），不夸大。
- **间接导入**：承认直接效应已被充分研究，但机制、条件或边界不清楚；或承认某方面进展显著，但另一相关方面长期被忽略。
- **重要性论证**：说明补上这块空白对理解更广的现象意味着什么。缺了这一步，空白读起来只是"别人没做"，而不是"应该做"。

三种方式常配合使用：直接或间接导入指出缺口，重要性论证说明为何值得补。空洞的空白声明（"该领域仍有广阔研究空间"）既没有定位，也没有论证价值。

## 8. 引文密度与引用组织

- 每段通常 5～12 条引用；主题句后的支撑证据宜有 3 条以上来源；关键论点需多源支撑，非关键背景可单源。
- **括号内多源**：结论一致的多项研究合并引用，按字母序或年份排列。
- **嵌入式引用**：只在某作者的具体贡献本身重要时使用，用于突出该研究的独特做法或发现，不用于代替综合。
- **综述引用**：已有综述覆盖的背景，引用综述而非重复罗列其全部来源。

引文密度是判断段落类型的信号：一段只有一两条引用却在承担重要主张，通常是证据不足；一段十几条引用却没有自己的判断，通常是在堆砌。

## 9. 交付前的判断

- 是否主题式组织，而非逐篇罗列？
- 每段是否有明确主题句，段落之间关系是否需要这些段落存在？
- 是否呈现了文献的演进或分歧，而不只是"有人做过"？
- 批判是否针对与本文相关的局限，是否忠实呈现被批评的立场？
- 空白的出现是否由前文推出，是否说明了补它的意义？
- 引文与所支持的论断是否一一对应（引用归属规则见 [证据、引用与实质修改](evidence-and-integrity.md)）？
- 本文定位与随后的假设或理论模型是否连续，有无承诺未兑现？

## 10. 语言差异

综述的篇幅、引用格式与句式习惯随目标语言不同：中文期刊见 [中文期刊规范](zh-journal-conventions.md)，英文期刊见 [英文期刊规范](en-journal-conventions.md)。本文件的结构与论证要求两种语言通用。
