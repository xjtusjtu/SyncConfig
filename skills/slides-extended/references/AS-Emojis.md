# AS-Emojis

Advanced Slides 支持 Emoji Shortcode：

```
:smile: => 😄
```

任何在 Markdown 笔记中编写的 shortcode 都会在幻灯片预览中自动显示为对应 emoji。

## 推荐插件

如果想在编辑模式中也看到 emoji 预览，可安装 [Obsidian Emoji Shortcodes](https://github.com/phibr0/obsidian-emoji-shortcodes) 插件。
